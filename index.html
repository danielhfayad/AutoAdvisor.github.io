    About the project

    AutoAdvisor turns car-search choices into structured decision logic.

    This project was built to demonstrate front-end development, data-driven UI rendering, user-centered design, filtering, sorting, recommendation scoring, and comparison workflows.

    What it shows

    JavaScript state management, JSON-driven rendering, dynamic filters, modals, localStorage favorites, and conditional recommendation logic.

    Why it matters

    Instead of being a static page, AutoAdvisor helps users make a decision. That makes it easier to explain in applications, interviews, and project portfolios.

    Next improvements

    Add more vehicle data, real market price ranges, ownership cost estimates, safety ratings, and a clearer source note for vehicle information.
