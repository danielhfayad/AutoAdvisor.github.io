# AutoAdvisor

AutoAdvisor is a student-built vehicle recommendation web app. It helps users narrow down car choices using searchable inventory, quick filters, a guided recommendation quiz, favorites, detailed vehicle cards, and side-by-side comparison.

## Features

- Search cars by make, model, year, body style, and price
- Sort by recommended score, price, MPG, reliability, or year
- Guided recommendation quiz with match scores and reasons
- Favorite vehicles saved in `localStorage`
- Vehicle detail modal with ratings and fit reasons
- Side-by-side comparison with highlighted winners
- Responsive design for desktop and mobile
- Static front-end project that works on GitHub Pages

## Files

- `index.html` — page structure and app sections
- `style.css` — responsive visual design
- `app.js` — filtering, sorting, recommendations, favorites, modals, and comparison logic
- `data/cars.json` — vehicle dataset
- `images/` — vehicle images

## Deployment

Push these files to the GitHub Pages repository. Since this is a static app, no build step is required.
